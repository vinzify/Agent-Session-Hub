# Antigravity CLI joins Agent Session Hub

Google Antigravity CLI is now the fourth supported provider, alongside Codex CLI,
Claude Code, and OpenCode.

## What's new

- Open Antigravity history with `agx` or `sessionhub antigravity`.
- Search by workspace, repository, branch, title, or local alias; preview index
  summaries and resume through `agy --conversation <id>`.
- See individual conversation sizes, including database, WAL, and shared-memory
  files, plus workspace totals.
- Read live SQLite index updates without decoding private step payloads,
  checkpointing databases, or launching the coding CLI during browsing.
- Use the new shortcut through bash, zsh, fish, PowerShell, and Windows cmd
  integration. Installers and uninstallers include it too.

The README now includes a four-provider capability table, Antigravity setup,
data paths, limitations, and upgrade guidance.

## Upgrade

For an installer-managed v0.4.x installation:

```sh
sessionhub update
sessionhub antigravity
```

To add the new `agx` shortcut as well, rerun the installer and reload your shell:

**Linux / macOS**

```sh
curl -fsSL https://github.com/vinzify/Agent-Session-Hub/releases/latest/download/install.sh | sh
```

**Windows PowerShell**

```powershell
irm https://github.com/vinzify/Agent-Session-Hub/releases/latest/download/install.ps1 | iex
```

Preserve any custom install/bin roots when rerunning the installer. Source and
package-manager builds should use their existing installation method. Self-update
does not change session data, aliases, or shell profiles.

## Antigravity scope

Install Google's `agy` CLI separately. This integration reads its local SQLite
store, normally `~/.gemini/antigravity-cli`, and shows indexed conversations with
a local conversation database and file-URI workspace. Older IDE-only histories
must first be imported through Antigravity's own `/resume` flow. Remote-only
entries are excluded, and multi-workspace conversations use the first local
workspace.

Previews use the CLI summary index, not full transcripts. Storage sizes exclude
shared indexes, artifacts, and caches. Antigravity deletion, connected agent
trees, and age-based cleanup are intentionally not supported in this release.

See the [README](https://github.com/vinzify/Agent-Session-Hub#google-antigravity-cli)
for configuration and provider capabilities.
