# v0.6.0 — Connected agents and recoverable cleanup

Manage growing local coding histories across Codex CLI, Claude Code, OpenCode,
and Antigravity CLI, without mixing agent logs into the main conversation list.

## What's new

- Connected agent trees for Claude, OpenCode, and Antigravity, alongside existing
  Codex support. `Ctrl-A` expands/collapses a chat's agents; searching for an agent
  preserves its parent chat. Ordinary Antigravity forks remain independent chats.
- Confirmed local-history deletion for Claude and Antigravity, with private
  compressed recovery copies and explicit list, restore, and purge commands.
- Agent/orphan cleanup for all providers, plus opt-in whole-chat cleanup with
  `--chats` (90 days by default). Normal root chats remain protected by default.
- Indexed cleanup families/cascade protection and sidecar-aware Claude caching.
- Expanded README, provider capability table, recovery instructions, and tests.

## Safe cleanup

Start with a non-destructive preview:

```sh
clx cleanup --dry-run --agents --older-than 60d
agx cleanup --dry-run --chats --older-than 90d
```

Remove `--dry-run` to select groups and confirm with `DELETE`. Whole-chat groups
must age together; cleanup will not select a Claude/OpenCode/Antigravity ancestor
whose deletion would include a newer or undeletable descendant. Codex-specific
security-scan grouping remains exclusive to Codex.

Claude and Antigravity deletion/restoration require the provider and background
workers to be closed. The hub refuses detected writers, changed files, symlinks,
busy indexes, and unsupported Antigravity schemas. It backs up selected files and
relevant metadata before removal. The process check is conservative, not a
cross-application lock: do not reopen the provider during an operation.

```sh
agx delete <session-id> --dry-run
agx delete <session-id> --yes
sessionhub antigravity recovery list
sessionhub antigravity recovery restore <backup-id>
sessionhub antigravity recovery purge <backup-id>
```

Use `sessionhub claude recovery ...` for Claude. Restore refuses conflicting newer
history and preserves unrelated records. Purge requires `PURGE` confirmation
(or explicit `--yes`) and is irreversible. Recovery backups contain private
conversation data and remain until explicitly purged, even after restoration.
Their stored sizes include the compressed archive and metadata manifest.

## Scope and limits

- This manages local CLI history, not project files, accounts, or separate
  IDE/cloud copies. Global prompt history and unrelated artifacts are not an
  all-traces-erased target.
- Claude deletion includes the transcript and files in its owned session subtree.
  Individual size displays still measure transcript bytes, not that whole subtree.
- Antigravity preserves opaque DB/WAL/SHM files for recovery and edits only known
  selected local summary/search/cache records, without undocumented provider RPCs.
- OpenCode uses its native CLI for deletion. Families with hidden archived
  descendants are protected; alternate hub-selected stores are browse-only so
  the native command cannot act on the wrong database. OpenCode payload sizes
  are estimates, not guaranteed disk space reclaimed.
- Existing Codex/OpenCode deletion does not use the new recovery-backup layer.
  Codex expanded-agent deletion still removes only that selected log; the other
  providers include connected descendants.

## Upgrade

```sh
sessionhub update
```

Automatic shortcut migration remains supported. To refresh optional shell
functions for `clx recovery` / `agx recovery`, run `sessionhub install-shell` and
reload your shell. Generic `sessionhub <provider> recovery ...` commands work
without that refresh. No automatic history cleanup or backup expiry is enabled.
