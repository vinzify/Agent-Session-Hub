# Automatic shortcut migration

Updating Agent Session Hub should also make newly introduced commands available.
This release fixes the missing shortcut migration that affected `agx` in v0.5.0.

## What's fixed

- Missing provider shortcuts are created automatically in the installer-recorded
  launcher directory, including custom paths.
- Updates run the newly installed version's migration after replacing the binary
  copies, including through the Windows post-exit helper.
- Existing commands, files, symlinks, and customized Windows wrappers are never
  overwritten by shortcut migration. Failed creation rolls back newly added files.
- No conversations, aliases, shell profiles, or private project data are changed.
  Source/package-manager builds are not automatically modified.

## Upgrade from v0.4.x or v0.5.0

```sh
sessionhub update
sessionhub providers
agx
```

The older updater cannot run new post-update logic. The first ordinary hub
command after upgrading repairs missing shortcuts locally; `sessionhub providers`
is a convenient way to trigger that one-time migration. There is no installer
rerun, additional download, or shell reload required for the new shortcut.

Updates run by v0.5.1 and newer perform migration immediately. Optional shell
functions that change your parent shell's working directory can be refreshed
separately with `sessionhub install-shell`, followed by reloading the shell.

Automatic migration does not run in hidden search/preview helpers or downloaded
version probes. The README and installation documentation include the new flow.
