# v0.6.1 — Lowercase version flag and menu regression coverage

`sessionhub -v` now prints the installed version instead of opening the provider
menu. It is an alias of the existing `-V`, `--version`, and `version` commands.
Provider-qualified commands and generated shell integration support it too.
Extra arguments to a version command are rejected without prompting for a provider.

## Menu validation

New end-to-end terminal checks exercise the public provider menu with fictional
histories and stub CLIs, without opening real conversations or contacting models:

- All four numbered choices open the corresponding picker and invoke the correct
  resume command after selection.
- Invalid choices retry; quit, empty input, and EOF cancel without launching a CLI.
- Named choices preserve the original search query, and explicit provider names
  bypass the menu.
- A missing native CLI produces a clear error rather than launching another provider.

The existing picker, connected-agent, search, and cancellation checks remain in
place. The README and command help now list all supported version forms.

## Upgrade

```sh
sessionhub update
sessionhub -v
```

For older Bash/fish provider shell functions, also run `sessionhub install-shell`
and reopen your terminal before using `csx -v`, `clx -v`, `opx -v`, or `agx -v`.
The generic `sessionhub -v` command works immediately after updating the binary.
Updates do not automatically rewrite shell profiles or modify conversations.
